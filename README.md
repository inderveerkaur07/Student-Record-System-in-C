# 🎓 Student Record Management System in C

This project is a console-based application developed using the **C Programming Language** and **Linked List Data Structure**. It is designed to efficiently store, manage, and organize student information through various record management operations.

The project was developed as part of an academic mini-project to strengthen practical knowledge of **Data Structures, Memory Management, and File Handling** concepts in C.

---

## 🚀 Features

- ➕ Add New Student Records
- 📋 View All Stored Records
- 🔍 Search Students by Roll Number
- ❌ Remove Student Records
- 📊 Arrange Records by Marks
- 🔤 Arrange Records Alphabetically by Name
- 📌 User-Friendly Menu Driven Program
- 💾 Data Saving Through `students.txt`

---

## 🧠 Concepts Applied

- Linked List Implementation
- Dynamic Memory Allocation
- Structures and Functions
- File Handling
- String Manipulation
- Pointer Operations
- Sorting Algorithms
